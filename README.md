## 📘 Overview

The **Security Vulnerability Detection Framework (SVDF)** performs multi-stage security scanning on C source code.  
It identifies vulnerabilities through:

1. **Static Analysis** – Pattern matching & signature detection  
2. **Dynamic Analysis (ASAN/UBSAN)** – Compiling and executing instrumented binaries  
3. **Mutation Fuzzing** – Auto-generating malicious inputs to trigger crashes  

SVDF produces:

- `report.json` (raw structured output)  
- `report.html` (human-readable styled report, generated by `make_report.py`)  
- Crash reproducer payloads  
- Sanitizer logs  

---

## ✨ Features

### ✅ 1. Static Vulnerability Scanner
Detects:

- Insecure functions: `strcpy`, `gets`, `sprintf`
- Buffer overflow patterns:  
  ```
  scanf("%s", buf)
  ```
- Hard-coded secrets  
- String-literal based credentials  
- Trapdoors using `strcmp(value, "secret")`

---

### ✅ 2. Dynamic Analysis with Sanitizers

Executed with:

- **AddressSanitizer (ASAN)**
- **UndefinedBehaviorSanitizer (UBSAN)**

Catches:

- Out-of-bounds reads/writes  
- Heap/stack corruption  
- Use-after-free  
- Crashes & aborts  

---

### ✅ 3. Mutation-Based Fuzzing

- Mutates seed inputs (`*.in` files)
- Attempts to crash compiled binaries  
- Logs crashing payloads in `reproducers/`  
- Saves ASAN stack traces  

---

### ✅ 4. Dark-Themed HTML Report Generator

Using the new file:  
```
make_report.py
```

You can convert JSON → clean, stylish HTML.

Includes:

- Vulnerability tables  
- Severity badges  
- Sanitizer results  
- Crash logs  
- Suggested fixes

## 🚀 Running the Framework

### **Step 1 — Run the Vulnerability Scanner**

Open terminal inside `svdf-project`:

```
py run.py
```

This generates:

```
reports/report.json
```

---

### **Step 2 — Generate the HTML Report (NEW COMMAND)**

Use your new report maker file:

```
py make_report.py
```

This creates a professional-looking report:

```
reports/report.html
```

It will open automatically in your default browser.

## 🔎 Example Vulnerabilities Detected

### Buffer Overflow
```c
scanf("%s", buf);   // No length limit → unsafe
```

### Hard-coded Credential
```c
char secret[] = "admin12345";
```

### Trapdoor / Backdoor
```c
if (strcmp(input, "opensesame") == 0) {
    grant_admin_access();
}
```
